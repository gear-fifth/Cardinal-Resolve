Concur Expense Report Issue Read Before Submitting

This service request is to be used when you are experiencing issues submitting your corporate credit expense reports via Concur. Issues can include, but are not limited to:

  • Intelligence Audit issues
  • Approver issues
  • Missing expense
  • Etc.
All requests must include details, including:
  • The team member's name who is having the issue
  • A screenshot of the issue
  • The team lead
