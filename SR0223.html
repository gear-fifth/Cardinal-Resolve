Floqast Entity / Folder Disposition Request Read Before Submitting

Please submit this Service Request (SR) to request the disposition of an entity and/or folder in Floqast. This should be submitted by the Property Accounting Manager (or with their approval).

  • Timing: The request should be entered after Accounting has completed all transition tasks for a property no longer under management (typically 30 days after the dispo date).
  • System Impact: Once this SR is submitted, all checklist and reconciliation tasks will be deleted from Floqast, and the entity or folder will be renamed to include "z - Dispo."

Thank you!
