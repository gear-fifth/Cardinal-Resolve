Standard Budget Packet Request Read Before Submitting

Use this SR to request the creation of a STANDARD budget packet. This packet will be created as an Excel file and shared with you via the corresponding community's Operating Budget folder in Google Drive.

Please ensure that you have OfficeConnect installed so that you can refresh the report with data from Adaptive. If you do not have OfficeConnect installed, please submit SR0181.

As a reminder: DO NOT OPEN THIS BUDGET PACKET IN GOOGLE SHEETS. You will break the formulas in the report if you do so, and the FP&A team will need to re-create your packet before you can use it.

If you need a custom report (anything outside of the standard packet), please submit SR0178 instead.
