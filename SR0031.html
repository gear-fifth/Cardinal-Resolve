New Charge Code Request Read Before Submitting

Please use this form to request any new charge codes needed in Entrata, Realpage, or Yardi.

  1. Charge code request is received.
  2. Systems support team reviews the request to determine if a new charge code is truly needed or if an existing code may be used instead.
  3. If a new charge code is needed, request is reassigned to Sarah Nadal.
  4. Sarah then takes the request to the next COA/Charge Codes Committee meeting to get approval from the group.
  5. Once approved, Sarah will create the charge code in the applicable PMS and will notify the team.
